# SPAGS 论文图像提示词（GPT image-2）

本文件用于生成 5 张论文方法图。目标风格参考：

- `FSGS Fig.2`
- `CoR-GS Fig.6`
- `R²-Gaussian Fig.4`
- `X-Gaussian` 的 CT / X-ray 视觉语境

统一要求：

- 白底，双栏论文内可读，横向构图
- 更像论文中的方法示意图，不像海报信息图
- 每张图只保留 `4–7` 个主视觉块
- 图内只允许短中文标签，标签尽量控制在 `2–6` 个汉字
- 线条细、边框细、箭头简洁、留白明显
- 配色克制：蓝、青、橙、灰，小面积点缀
- 不要卡通图标、不要立体积木、不要营销式大标题、不要装饰底纹
- 不要密集文字，不要把图做成表格，不要塞公式，不要伪 UI

建议工作流：

1. 每张图生成 `v1 / v2 / v3`
2. `v1` 先看结构和留白
3. `v2` 修正模块关系与中文标签
4. `v3` 压缩文字密度，强化论文感
5. 最终从三版里选一张进入正文

# Intro

稀疏视角 CT 新视图合成的目标，是在尽可能少的 X 射线投影下恢复高质量的新角度投影，以降低辐射剂量并保留诊断或分析所需的结构细节。与自然图像新视图合成不同，CT 观测满足穿透式成像机制，单个像素对应整条射线上的衰减累积，因此问题高度病态，对初始化、几何约束和密度建模都更加敏感。

近两年，3D Gaussian Splatting（3DGS）凭借显式表示和高效栅格化，在新视图合成中取得了明显的速度优势。围绕稀疏视角场景，FSGS 通过邻近引导的高斯扩增补足覆盖不足，CoR-GS 通过双场分歧做协同正则，DNGaussian 用深度正则来修复稀疏视角下的几何退化，X-Gaussian 与 R²-Gaussian 则把 3DGS 推进到 X 射线与 CT 领域。它们共同说明：在 sparse-view 条件下，决定性能上限的不是单纯的渲染速度，而是如何稳定地约束高斯的空间分布与密度演化。

我们的核心观察是：在稀疏视角 CT 场景里，主要矛盾并不只是“覆盖不够”，而是“结构冗余被错误放大”。传统 3DGS 的梯度驱动密化会持续在骨骼和软组织边界堆叠高斯，导致表示容量被高对比边界吞噬，而低对比组织内部却得不到足够稳定的密度建模。基于这一判断，我们提出 SPAGS，从初始化、密度控制和密度优化三个阶段显式引入空间感知。

# Related Work

## Sparse-view 3DGS

FSGS 将 sparse-view 3DGS 的核心问题理解为“初始点云过于稀疏，场景覆盖不足”，因此提出 proximity-guided Gaussian unpooling，在已有高斯之间插入新的高斯以提升覆盖率，并结合伪视角与深度先验约束几何。CoR-GS 则从训练不稳定性出发，观察到两个独立优化的高斯场会在点位置与渲染结果上产生 disagreement，并据此构造 co-pruning 与 pseudo-view co-regularization。DNGaussian 强调 sparse-view 退化本质上是一种几何退化，因此以单目深度为外部监督，提出 Hard/Soft Depth Regularization 和 Global-Local Depth Normalization 来修正高斯几何。

这些方法都有效推动了 sparse-view 3DGS 的发展，但它们默认的场景前提主要来自自然 RGB 任务：三维结构由可见表面主导，大量空间本身为空，因此“补足覆盖”或“修复表面几何”是更重要的问题。CT 场景则不同，体空间被连续密度场占据，真正的难点往往是边界附近的高斯冗余与密度估计失衡。

## X-ray / CT 3DGS

X-Gaussian 首次将 3DGS 系统性引入 X 射线新视图合成，提出 radiative Gaussian point cloud、Differentiable Radiative Rasterization 和 ACUI 初始化，使 3DGS 可以在 X 射线物理下高效工作。R²-Gaussian 进一步发现标准 3DGS 在体重建任务中存在积分偏差，并通过 radiative kernel、X 射线栅格化与可微体素化建立了首个真正面向稀疏视角 CT 断层重建的 3DGS 框架。

这些工作奠定了 CT-3DGS 的物理正确性与高效渲染基础，但在优化策略层面，仍保留了较多通用 3DGS 的默认假设：初始化仍缺少解剖复杂度感知，密度控制仍容易被高梯度边界主导，密度更新也缺乏连续空间上下文。SPAGS 的工作正是沿着这个缺口继续往前推进。

# Method

SPAGS 由三个顺序衔接的模块组成：

1. SPS（Spatial Prior Seeding）  
   用 FDK 粗重建作为体密度先验，对初始高斯进行“密度加权采样 + 均匀补偿采样”。这样既能把更多高斯放到解剖相关区域，又不会完全丢失低密度区域的全局覆盖。

2. GAP（Geometry-aware Pruning）  
   不再把“高梯度 = 需要补点”当作唯一信号，而是在三维世界坐标系中计算高斯的邻近度，并结合梯度活跃性过滤，剪除那些局部过于拥挤但学习价值已经不高的高斯。它直接针对 CT 场景里最严重的边界冗余问题。

3. ADM（Adaptive Density Modulation）  
   用 K-Planes 对位置进行编码，再通过轻量解码器预测密度偏移与置信度，实现位置相关的密度调制。这样不同解剖区域就不必共享完全相同的密度更新规律，骨骼、软组织和空气区域可以拥有更合理的局部修正。

三者串起来形成一条很清晰的链路：SPS 负责“从哪里开始”，GAP 负责“哪些高斯该删”，ADM 负责“留下来的高斯该怎么按区域调密度”。

# Experiment

我们在 5 个器官场景上评估方法：Chest、Head、Abdomen、Foot 和 Pancreas，并在 2/3/4 视角设定下与 5 个核心基线比较：DNGaussian、CoR-GS、FSGS、X-Gaussian 和 R²-Gaussian。

主结果显示，SPAGS 在三个视角设置上都保持最优或并列最优，其中在最关键的 3-view 设定下平均 PSNR 达到 28.22 dB，相比 R²-Gaussian 提升 0.39 dB。这个设定最能体现 SPAGS 的价值：信息不足以让基线自然收敛到理想几何，但又还没有病态到任何先验都无效，因此空间感知初始化、冗余控制和密度调制都可以真正发挥作用。

消融实验进一步说明，GAP 是最有决定性的模块：它单独使用就能带来最明显、最稳定的收益，证明在稀疏视角 CT 里，结构冗余控制是比单纯补点更关键的优化方向。SPS 和 ADM 的主要价值则体现在稳定训练轨迹、改善初始分布以及提供更平滑的局部密度修正。

# Conclusion

SPAGS 面向稀疏视角 CT 新视图合成，在 3DGS 的初始化、密度控制和密度优化三个阶段显式引入空间感知。与主流 sparse-view 3DGS 方法主要围绕补点、外部深度监督或双场协同不同，SPAGS 的核心判断是：CT 场景中的主要瓶颈往往是结构冗余，而不是单纯的覆盖不足。

围绕这一判断，我们提出了 SPS、GAP 和 ADM 三个互补模块。实验表明，该框架在 5 个器官和 2/3/4 视角设定下均能稳定提升性能，尤其在 3-view 核心场景下最具优势。后续可以继续探索跨器官自适应参数设置、4DCT 场景扩展以及与更强学习型体先验的结合。

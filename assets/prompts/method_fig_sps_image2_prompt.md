# method_fig_sps — image2 绘图提示词（3D 体积方块风格）

## 用途

- 论文：`XRA-GS: X-ray Attenuation-Aligned Gaussian Splatting for Sparse Tomographic View Synthesis`（PG2026 投稿）
- §3.3 Support-Profile Seeding 配图。展示 SPS 如何把 FDK 体积转成密度加权采样分布，再得到路径锚定的初始高斯集。
- 与 pipeline / GAP / ADM 三图视觉统一：同一调色板体系、同一无衬线字体、同一箭头粗细。SPS 主色蓝 `#1F77B4`。
- 输出文件名：`method_fig_sps.png`，落地 `assets/fig/`。
- backup 规则：已存在同名图 → 移旧图为 `_backup.png`（已存在 backup 时不重建）。

## 总版式

- 整体布局：**水平三阶段流程图**，从左到右，每阶段核心是 3D 线框立方体（等轴测视角，约 30° 俯视），阶段间用灰色细实线箭头连接。
- 图幅宽高比约 **16:6**（约 1600 × 600 px，dpi ≥ 300），纯白底。
- 每阶段上方居中加粗无衬线标题（8–9pt）。
- 全图主色蓝 `#1F77B4`（区别于 GAP 橙、ADM 绿）。

## 三阶段内容

### Stage 1 — 输入（左侧）

**标题**：上方标 `Sparse Projections`，下方标 `FDK Prior`

视觉构成：
- **上方**：3~4 张灰度 X-ray 投影图略带透视地堆叠（前一张略遮后一张），每张为矩形灰度影像，暗示稀疏输入。影像内容为模糊的头骨/解剖轮廓。
- **下方**：一个 3D 线框立方体（细灰线边框），内部渲染半透明灰白色体积数据——可隐约看到模糊的颅骨/解剖结构轮廓（FDK 粗重建，有条纹伪影感），整体灰蒙蒙的。
- 上方投影图组和下方 FDK 立方体之间用一个收束花括号或两条汇聚箭头连向 Stage 2。

### Stage 2 — 概率采样（中间）

**标题**：`Density-Weighted Mixture`

视觉构成：
- **主体**：一个 3D 线框立方体，内部填充密度热力图（蓝→黄→红暖色渐变）。热力图在高密度解剖区域（颅骨位置）显示红/暖色，低密度空气区域显示蓝/冷色。立方体侧面可见渐变色条，标注 `High` / `Low`。
- **右侧附加**：一个小号 3D 线框立方体，内部均匀散布约 15~20 个蓝色小圆点 `#1F77B4`（表示均匀分布项 `α/|Ω|`）。
- 主热力图立方体与小均匀立方体之间放一个 `+` 号，表示混合。
- 底部居中一行短公式 `q = α/|Ω| + (1−α) p`（8pt LaTeX 风格深灰）。
- 底部图例：一个红色小圆点标 `density-weighted`，一个蓝色小圆点标 `uniform prior`。

### Stage 3 — 初始高斯（右侧）

**标题**：`Seeded Gaussians`

视觉构成：
- 一个 3D 线框立方体，内部散布约 **20-25 个**深蓝 `#1F77B4` 半透明**扁平 2D 椭圆**（≤25 个硬限制）。
- **Gaussian 必须画成扁平纯色 2D 椭圆，绝对禁止画成 3D 球体、有高光的球、有光影渐变的椭球。**
- 椭圆在高密度区域（对应 Stage 2 暖色区域）放几个**较大的椭圆**，松散覆盖解剖区域。
- 低密度空气区域放几个**较小的椭圆**，稀疏散布，体现 uniform mixture 项保留了全局覆盖。
- **不要试图用密集椭圆描出颅骨轮廓**——用少量大元素松散覆盖即可（以小见大原则）。
- 整体呈现"解剖结构区域密集 + 背景少量散布"的双重分布。
- **zoom-in 放大区域**：从立方体中标注一小块区域（彩色矩形框），引出放大视图。放大区域内**必须有额外视觉标注**：
  - 2-3 个扁平椭圆，大的标注 `high ρ`（高密度），小的标注 `low ρ`（低密度）
  - 用虚线箭头标注椭圆的大小差异方向（从小到大）
  - 用文字标注说明"密度越高 → 椭圆越大"的对应关系

## 阶段间连接

- Stage 1 → Stage 2：灰色实线右向箭头 `#888888`，1.5pt，箭头中段标 6pt 灰字 `weight by V_FDK^γ`。
- Stage 2 → Stage 3：灰色实线右向箭头 `#888888`，1.5pt，箭头中段标 6pt 灰字 `sample`。

## 配色规范

- 蓝 `#1F77B4`：Stage 3 初始 Gaussians 扁平椭圆、Stage 2 均匀分布小点（SPS 主色）
- 蓝→黄→红暖色渐变：Stage 2 密度热力图
- 灰白色半透明：Stage 1 FDK 粗体积渲染
- 中性灰 `#888888` / `#BFBFBF`：立方体线框、箭头、标题、底部说明、公式
- **不使用**：橙（属于 GAP）、绿（属于 ADM）、霓虹、3D 软阴影

## 全局字体规范（5 张图统一）

- 全图仅使用 2 种字体样式：①标题=加粗无衬线（Helvetica Bold / Arial Bold 风格），②描述性文字=常规无衬线（Helvetica Regular / Arial Regular 风格）
- 阶段标题（Sparse Projections / Density-Weighted Mixture / Seeded Gaussians）: 加粗无衬线，8-9pt
- 底部说明/图例: 常规无衬线，7pt，灰色 #757575
- 箭头中段标注: 常规无衬线，6pt，灰色 #888888
- 烘焙公式: 8pt LaTeX 风格深灰斜体
- 严禁出现衬线体（Times/Serif）、手写体、装饰体
- 所有文字字号与本系列其他 4 张图（intro/pipeline/GAP/ADM）保持一致
- **严禁** 在图内出现 `(a)(b)(c)` panel 编号

## 文字烘焙白名单

- 可烘焙：`Sparse Projections` / `FDK Prior` / `Density-Weighted Mixture` / `Seeded Gaussians` / `q = α/|Ω| + (1−α) p` / `V_FDK^γ` / `weight by V_FDK^γ` / `sample` / `High` / `Low` / `density-weighted` / `uniform prior`
- 严禁烘焙：dataset 名、view 数、PSNR、SSIM、α 与 γ 的具体数值、50K 初始高斯数、任何完整句子、caption 文字

## 反例

- 严禁概率密度热图使用纯绿色或 viridis（必须蓝→黄→红暖色）
- 严禁 Stage 3 用密集小点临摹颅骨轮廓（必须用 ≤25 个大椭圆松散覆盖 + 少量背景散布，以小见大）
- **严禁 Stage 3 的 Gaussian 画成 3D 球体**——必须是扁平纯色 2D 椭圆，没有高光、没有光影、没有立体感
- 严禁出现 SPS·GAP·ADM 三 badge 排列（badge 只在 pipeline 图出现一次）
- 严禁使用玻璃质感、UI 卡片背景、技术博客封面风格

# 对比实验协议（锁定）

后续只要涉及主文实验、实验规划、结果汇报、表格设计、图注撰写或摘要中对实验结论的概括，默认采用本协议，避免对比对象、指标、数据设定来回漂移。

## 固定对比方法（6 个）

- `CoR-GS`
- `DNGaussian`
- `FSGS`
- `X-Gaussian`
- `R2-Gaussian`
- `X-Field`

## 对比规则

- 默认主对比就是上述 6 个方法，不临时替换
- 后续需补 baseline 默认放补充材料或经用户明确指令后再进入主文
- 主文 qualitative figure / quantitative table / caption / 正文分析 / 摘要结果概述默认围绕这 6 个方法
- 方法名统一使用论文名对应标准写法，不混用文件名、缩写变体或临时别名

## 主指标规则

- 主指标固定为 `SSIM2D` 和 `PSNR2D`
- 主文表格、结果分析、摘要 / 引言提炼实验结论时，优先围绕 `SSIM2D` 和 `PSNR2D` 组织
- 报告额外指标时视为辅助指标，不能盖过主指标地位
- 默认保持指标命名统一，不写成 `SSIM` / `PSNR` 的模糊形式，除非上下文已明确限定为 2D 投影指标

## 测试设定

- 测试数据集默认 `5` 个器官
- 视角设置默认固定在 `2`、`3`、`4` 视角
- 主对比表、主结果图、摘要 strongest result、引言概括实验结论，默认建立在 `5 organs × {2,3,4} views` 设定上
- 若某结果不来自本设定，正文和 caption 必须显式标明

## 呈现要求

- 主表让读者一眼看出 `2/3/4` 视角下、`5` 个器官上的 `SSIM2D` / `PSNR2D` 对比结果
- 实验段落优先总结跨视角趋势、极稀疏视角表现、5 个器官整体稳定性
- 压缩主文篇幅时，优先保留这套固定协议下最强的 figure/table，细节扩展进补充材料

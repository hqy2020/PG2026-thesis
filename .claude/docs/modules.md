# 三个创新模块：SPS / GAP / ADM

`XRA-GS` 的方法主体由三个创新模块组成，固定顺序、固定命名，不得在改稿中漂移。

## 模块定位

- `SPS`（初始化）：基于 FDK 粗重建提供的前景支撑与粗衰减轮廓做路径锚定初始化
- `GAP`（结构控制）：回收边界附近由误差/梯度驱动带来的冗余高斯
- `ADM`（细化）：基于连续空间上下文做位置相关的密度调制与局部稳定细化

## 写作硬规则

- 正文介绍创新点默认就是这三个模块，顺序按 `SPS → GAP → ADM`
- 图中模块名、表格 ablation 行名、补充材料小节名统一用 `SPS / GAP / ADM`
- 消融实验命名：`w/o SPS`、`w/o GAP`、`w/o ADM`、`full XRA-GS`
- `XRA-GS` 是总方法名，`SPS / GAP / ADM` 是其内部创新点，不要写成互相替代关系
- 三个模块缺一不可，不要在改稿中遗漏其中任何一个
